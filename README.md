# 📱 Sistema de Apoio à Comunicação Alternativa e Aumentativa (CAA) para TEA

Projeto de Trabalho de Conclusão de Curso (TCC) focado em Comunicação Alternativa e Aumentativa para pessoas com Transtorno do Espectro Autista.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Flet** (Interface moderna mobile)
- **SQLite3** (Banco de dados relacional offline)
- **Google GenAI** (Otimização e refinamento assistido de frases via Gemini)

## 🚀 Como Executar
1. Instale os requisitos:
   ```bash
   pip install flet pyttsx3 google-genai
